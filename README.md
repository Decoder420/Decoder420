### 🛡️ About Me

I am a security engineer and developer focused on turning security problems into resilient, automated solutions. My work bridges **defensive detection engineering** (SIEM, Sigma rules, YARA, threat hunting) and **offensive security automation** (DAST, vulnerability assessment, SSRF guardrails, credential vaulting), alongside integrating **machine learning models** for predictive risk evaluation.

- 🔍 **Defensive Operations**: Detection engineering, MITRE ATT&CK mapping, Sysmon log analysis, and incident triage.
- ⚡ **Security Tooling**: Building modular, observable platforms that orchestrate scanners (OWASP ZAP, Nuclei) with full-stack interfaces.
- 🤖 **AI & Security**: Applying statistical analysis and machine learning to threat intelligence, anomaly detection, and automated risk scoring.
- 🚀 **Philosophy**: *"Turning security telemetry into proactive defense."*
